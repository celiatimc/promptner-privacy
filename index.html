Promptner — 隐私政策

最后更新：2026 年 4 月 26 日（v1.9.0 · 云同步范围扩展）

Promptner 是一款 Chrome 浏览器扩展程序，用于管理 AI 提示词（含文本与图片两类内容）。我们非常重视您的隐私，本政策说明我们如何收集、使用和保护您的数据。

1. 数据收集

Promptner 收集并存储以下数据，全部保存在您的本地设备上（通过 chrome.storage.local）：

  • 文本提示词：您创建的提示词内容（标题、正文、分类、标签、收藏 / 归档状态等）
  • 图片提示词（v1.2.3 起支持）：您自行上传或粘贴的图片（每条提示词最多 3 张）· 客户端压缩为 WebP 格式后本地存储 · 原图字节与缩略图字节均不出设备
  • 草稿箱：您在草稿箱内暂存的长文本编辑内容
  • 归档（v1.5.0 起由归档替代回收站）：被归档的提示词 / 图片软保护存储，可在【归档】视图取消归档；选择【彻底删除】时物理移除
  • 本地存档（v1.0.0 起 · v1.4.0 简化为单份）：您主动点击【存档】后生成的数据快照（文本 / 图片各自独立一份 · 每次存档覆盖上一次）
  • 扩展设置：主题偏好、快捷键配置、站点规则等
  • 云同步状态信息（仅启用云同步时）：同步模式、上次同步时间等

2. Google Drive 云同步（可选功能 · v1.9.0 起范围扩展）

当您启用「云同步」功能时，Promptner 将通过 Google OAuth2 认证获取您的 Google 账号授权，并使用 Google Drive API 将您的扩展数据上传到 Google Drive 的 应用私有数据文件夹（appDataFolder） · 该文件夹仅当前扩展可读写 · 您在 Google Drive 网页端不会看到这些文件 · 但仍占用您 Google Drive 配额。

  • 访问范围：仅访问 Promptner 自身创建的文件（drive.appdata scope · 与 v1 起一致 · 未升级）· 不会访问您 Google Drive 中的任何其他文件
  • v1.9.0 起会同步上传的内容：
    • 文本提示词（标题 / 内容 / 分类 / 收藏 / 归档状态等 · v1 起即在云同步范围内）
    • 视觉提示词元数据 + 缩略图（v1.9.0 新增 · 标题 / 模型名 / 标签 / 缩略图等元数据）
    • 视觉提示词原图（v1.9.0 新增 · 客户端压缩后的 WebP 字节流 · 单张 ≤10MB · 通过 SHA-256 内容寻址 · 同图不重复上传）
    • 本地存档最新槽（v1.9.0 新增 · 文本 + 视觉各 1 份最新存档 · 历史 2 份不上传以节省带宽）
    • 草稿箱内容（v1.9.0 新增 · 单文档 · 后写者胜合并）
  • 仍不同步的内容：扩展设置（主题 / 快捷键 / 站点规则） · 历史存档（除最新槽外的 2 份） · 浏览器内置同步状态 · 您 Google 账号的任何其他数据
  • 触发方式：
    • 文本与草稿：自动后台同步（30 秒延迟去抖 + 30 分钟周期性 alarm · 与 v1 一致）
    • 图片原图与本地存档：仅手动触发（您在扩展设置面板点【全量同步】按钮 · 起飞前显示数据量 / 预计耗时 / 网络状况确认对话框 · 默认开启「仅 WiFi / 4G / 5G」可在 2G/3G 弱网下阻断同步避免耗流量）
  • 合并策略：所有数据采用「后写者胜」（Last-Write-Wins · 按 updatedAt 时间戳）合并 · 多设备并发编辑同一对象时 · 时间戳较晚的版本胜出
  • 您的控制权：
    • 随时在扩展设置中关闭云同步、登出 Google 账号
    • 从 Google 账号设置 撤销 Promptner 的访问权限
    • 删除云端数据：Google Drive 网页端 → ⚙ 设置 → 管理应用 → Promptner → 删除隐藏的应用数据（一次性清除全部 appData 私有文件夹内容）
    • 同步过程中可随时点【暂停】/【取消】按钮中止 · 不会损坏本地数据
  • 可选性：云同步完全可选 · 不登录不影响扩展任何其他功能的使用

3. 数据传输

  • 所有与 Google 服务的通信均通过 HTTPS 加密连接
  • OAuth2 token 由 Chrome 浏览器内置的身份认证系统管理 · Promptner 不存储您的 Google 密码
  • 除 Google Drive 云同步外 · Promptner 不会向任何第三方服务器发送您的数据
  • v1.8.x 及更早版本：图片数据不参与任何网络传输 · 仅在您本地设备的 Chrome 存储中读写
  • v1.9.0 起（仅启用云同步且您主动点击【全量同步】时）：图片数据通过 HTTPS 上传至您 Google Drive 私有数据文件夹（appDataFolder） · 不经任何第三方中转

4. 数据共享

我们 不会 出售、出租或以其他方式与第三方共享您的个人数据。您的提示词数据仅存储在：

  • 您的本地浏览器存储中
  • 您自己的 Google Drive 账号中（仅文本部分 · 仅在启用云同步时）

5. 权限说明

Promptner 请求以下浏览器权限 · 每项权限用于特定功能：

  • storage：在本地存储提示词、图片、设置、草稿箱、本地存档等数据
  • unlimitedStorage（v1.2.3 起）：图片提示词的原图与附加图以独立键值存储 · 为支持用户自由管理图片数量（单张最大 10 MB · 总量按设备磁盘空间为限） · 需申请无限存储配额 · 全部数据仍保留在本地 · 不涉及任何外部网络传输或上传
  • tabs：读取当前标签页 URL 以匹配站点规则 · 或在用户点击"添加当前网站"时获取 URL 模板 · 不读取页面内容、不读取浏览历史
  • scripting：在匹配的 AI 站点动态注入悬浮工作台 UI（Shadow DOM 隔离） · 不访问页面 DOM、不读取对话内容
  • identity：仅当您主动启用云同步时触发 · 使用 Chrome Identity API + Google OAuth2 获取 token · 不启用则完全不触发
  • alarms：云同步定时器（每 30 分钟）+ 数据变更 30 秒防抖调度 · 不用于其他目的
  • host_permissions（5 个 AI 域名）：chatgpt.com / chat.openai.com / claude.ai / gemini.google.com / www.perplexity.ai · 仅用于注入悬浮工作台 · Shadow DOM 运行 · 不读对话、不上传
  • optional_host_permissions：http://*/* 和 https://*/* · 仅当您手动添加自定义站点且原生授权弹窗点"允许"时按站点逐一授予 · 从不一次性请求所有网站

6. 远程代码

Promptner 扩展不加载任何远程代码（no eval / no external scripts / no remote modules） · 所有 JavaScript / CSS / 字体 / 图标均随扩展包分发。与 Google Drive API 的交互仅限数据交换 · 不涉及代码执行。

7. 数据删除

您可以随时通过以下方式删除数据：

  • 在扩展工作台中归档单条提示词（可在【归档】视图取消归档；选择【彻底删除】则物理移除 · 双重二次确认防误操作）
  • 再次点击【存档】即覆盖上一份存档（文本 / 图片各自独立一份）
  • 卸载扩展程序（将清除所有本地数据 · 包括图片原图）
  • 云端数据删除：Google Drive 网页端 → ⚙ 设置 → 管理应用 → Promptner → 删除隐藏的应用数据（一次性清除全部 appData 私有文件夹内容 · 包括 v1.9.0 上传的图片原图 / 视觉元数据 / 本地存档 / 草稿箱）

8. 儿童隐私

Promptner 不面向 13 岁以下的儿童 · 我们不会有意收集儿童的个人信息。

9. 政策变更

如本隐私政策发生变更 · 我们将在此页面更新内容并修改「最后更新」日期。重大变更（如新增数据类型或涉及传输的权限）将通过扩展更新日志明确通知用户。

10. 联系方式

如对本隐私政策有任何疑问 · 请通过 Chrome Web Store 扩展页面的支持渠道联系我们。
